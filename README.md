# 💧 HydroTimer

HydroTimer is a simple hydration companion designed to help users build consistent water-drinking habits through  goal tracking, and progress monitoring.

## Overview

Most people know they should drink more water, but busy schedules make it easy to forget. HydroTimer helps users stay hydrated by providing a quick way to track water intake and receive reminders throughout the day.

The goal is not to overwhelm users with complex health metrics but to create a lightweight and practical hydration experience.

## Features

### 🚰 Daily Hydration Tracking

* Log water intake with a single tap.
* Track progress toward daily hydration goals.
* View remaining water needed to reach the target.

### 📊 Progress Monitoring

* Daily hydration progress visualization.
* Goal achievement tracking.
* Historical hydration records.

### 🎯 Personalized Goals

* Set custom daily water intake targets.
* Adjust goals according to personal preferences.

### 📱 Responsive Experience

* Works seamlessly across desktop and mobile devices.
* Clean and distraction-free interface.

## Problem Statement

Many hydration applications are either too complicated or filled with unnecessary features. HydroTimer focuses on solving one problem well:

**Helping users remember to drink water consistently throughout the day.**

## Installation

```bash
git clone https://github.com/your-username/hydrotimer.git

cd hydrotimer

npm install

npm run dev
```

## Run Locally

**Prerequisites:**  Node.js


1. Install dependencies:
   `npm install`
2. Set the `GEMINI_API_KEY` in [.env.local](.env.local) to your Gemini API key
3. Run the app:
   `npm run dev`
